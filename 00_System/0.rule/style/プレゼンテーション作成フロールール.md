# プレゼンテーション作成フロールール（2025年11月版）

## 概要

Obsidian + Claude Code + Marpによる完結型プレゼンテーション作成フロー。文字数制限を厳守し、26pt以上のフォントサイズを保証する。

## 適用条件

### トリガーワード
- `スライド作成`
- `プレゼン作成`
- `プレゼンテーション`
- `発表資料`

### 作成タイプ
- **タイプA：対話型** - スライド1から順番に一緒に作る
- **タイプB：自動化型** - 既存資料（報告書など）から自動生成

---

## 文字数制限（厳守）

### 言語別制限

#### 日本語
- **タイトル**: 20文字以内
- **本文・箇条書き（1項目）**: 30-35文字以内

#### 英語・フランス語
- **タイトル**: 30-35文字以内
- **本文・箇条書き（1項目）**: 80文字以内

### 共通ルール
- **箇条書き項目数**: 3-5項目まで
- **1スライド最大行数**: 5行まで
- **最小フォントサイズ**: 26pt（厳守）

---

## タイプA: 対話型スライド作成

### フロー

```
1. ユーザー: 「スライド作成して」
   ↓
2. Claude: 基本情報をヒアリング
   - 対象聴衆
   - 時間
   - 目的
   - 言語（日本語/英語/フランス語）
   ↓
3. スライド1から順番に作成
   - ユーザーと対話しながら内容を決定
   - 文字数制限をリアルタイムチェック
   - スライド構成を確認
   ↓
4. 次のスライドへ
   - スライド2, 3, ... と順番に作成
   - 各スライドで文字数確認
   ↓
5. 全スライド完成後、Marpデザイン適用
   ↓
6. プレビュー確認・微調整
```

### Claude Codeの動作

各スライド作成時：
```markdown
## スライド1: [タイトル]

【内容案】
- 項目1（〇〇文字）
- 項目2（〇〇文字）
- 項目3（〇〇文字）

✅ 文字数チェック：
- タイトル: XX文字 / 20文字
- 項目1: XX文字 / 35文字
- 項目2: XX文字 / 35文字

【このスライドでOKですか？】
```

## タイプB: 自動化型スライド作成

### フロー

```
1. ユーザー: 既存資料を提供
   ↓
2. Claude: 資料を分析
   - 内容の抽出
   - プレゼン用に再構成
   - 文字数に合わせて分割
   ↓
3. スライド構成を自動生成
   - 各スライド30-35文字以内に調整
   - 長い場合は複数スライドに分割
   - 重要度に応じて取捨選択
   ↓
4. 生成されたスライド一覧を提示
   ↓
5. ユーザー確認・修正
   ↓
6. Marpデザイン適用
   ↓
7. プレビュー確認・微調整
```

### 自動生成の原則

#### 文字数超過時の対応
**NG例（1スライドに詰め込みすぎ）：**
```markdown
# プロジェクト概要

- カメルーン共和国における小規模農家のキャッサバ生産性向上を目指した技術協力プロジェクト（60文字超）
- 2023年から2026年までの3年間で5地域200農家を対象に実施予定（40文字超）
```

**OK例（複数スライドに分割）：**
```markdown
# プロジェクト概要

- カメルーン農業技術協力プロジェクト（20文字）
- キャッサバ生産性向上を目指す（17文字）

---

# 実施体制

- 期間：2023-2026年（3年間）（18文字）
- 対象：5地域200農家（13文字）
```

#### 情報の取捨選択
- **残すもの**: 核心メッセージ、数値、結論
- **削るもの**: 詳細な説明、背景情報、補足

## Marpデザイン適用

### 使用テーマ
`warm-business-theme.css` - 温かみのあるビジネステーマ

### デザイン仕様
- **アスペクト比**: 16:9（1920×1080px）
- **背景色**: 温かみのあるベージュ (#faf8f3)
- **見出し色**: 茶色 (#6d4c41)
- **アクセント色**: オレンジ (#f57c00)
- **本文色**: 濃いグレー (#424242)
- **フォントサイズ**:
  - タイトル(h1): 56pt
  - 見出し(h2): 42pt
  - 本文: 28pt（最小26pt厳守）

### Marpヘッダー設定

```markdown
---
marp: true
theme: warm-business
size: 16:9
paginate: true
header: ''
footer: ''
style: |
  @import url('00_System/0.rule/style/warm-business-theme.css');
---
```

### タイトルスライド

```markdown
<!-- _class: title -->

# プレゼンテーションタイトル

サブタイトルまたは日付

発表者名
```

### 通常スライド

```markdown
# スライドタイトル

- 箇条書き項目1（30文字以内）
- 箇条書き項目2（30文字以内）
- 箇条書き項目3（30文字以内）
```

### 2カラムレイアウト

```markdown
# 2カラムスライド

<div class="columns">
<div>

左側のコンテンツ
- 項目1
- 項目2

</div>
<div>

右側のコンテンツ
- 項目3
- 項目4

</div>
</div>
```

## Google Slidesへのエクスポート

### 手順

1. **Obsidianで作成したMDファイルをMarpでプレビュー**
2. **PDF/PPTXにエクスポート**
   - Marpプラグインの「Export」機能を使用
   - または、Marp CLIでエクスポート
3. **Google Slidesにインポート**
   - Google Driveにアップロード
   - Google Slidesで開く
4. **画像追加・最終調整**
   - Google Slidesの画像検索機能で自動生成
   - レイアウト微調整

## トラブルシューティング

### 文字がはみ出る場合
1. **文字数を再確認** - 制限を超えていないか？
2. **複数スライドに分割** - 1スライドの情報量が多すぎる可能性
3. **表現を簡潔に** - 冗長な部分を削る

### レイアウトがずれる場合
1. **2カラムレイアウト使用時** - `<div class="columns">` を正しく閉じているか？
2. **画像サイズ** - 大きすぎる画像はスライドからはみ出る
3. **CSSの確認** - warm-business-theme.cssが正しく読み込まれているか？

### Marpプレビューが表示されない
1. **ヘッダー設定確認** - `---` で囲まれたYAMLヘッダーが正しいか？
2. **CSSパス確認** - `@import url()` のパスが正しいか？
3. **Marpプラグイン有効化** - Obsidianの設定で有効になっているか？
