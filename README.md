# 📚 読書を何倍も楽しくする Claude Code Project

読書中にAIと対話しながら理解を深め、読了時には整理された読書ノートが自動的に完成する読書サポートアプリ。

## ✨ コンセプト

「読書しながらAIと対話できたら、もっと理解が深まるのに...」

このプロジェクトは、そんな願いを実現します。わからない用語をすぐ質問したり、自分の考えを整理したり、AIと議論したり。すべての対話がログとして残り、最後には美しく整理された読書ノートが完成します。

## 🎯 現在の機能（教養書モード）

### ✅ 実装済み

- 🗂️ 本ごとにデータを整理

## 🔄 Mac ⇄ スマホ 双方向同期

このプロジェクトは、Obsidianを使ってMacとAndroidスマホの間で双方向同期します。

### 同期の仕組み

```
[Mac: ローカルObsidianフォルダ]
    ⇄ rsync 双方向（30分おき自動）
[Google Drive: ~/Library/CloudStorage/.../obsdian-sync]
    ⇄ Google Driveアプリ（自動）
[Android: Obsidian]
```

- **Mac側**: rsyncで双方向同期（30分おき）
- **スマホ側**: Google Driveアプリ経由で自動同期
- **どちらで編集してもOK**: 変更は自動的に反映されます
- **同期対象**: 7つの主要フォルダ（30_Knowledgeに読書ノートを含む）

### セットアップ

詳しい手順は [`docs/obsidian-sync-setup-guide.md`](docs/obsidian-sync-setup-guide.md) を参照してください。

**簡単な流れ**:
1. 既存の一方通行同期を停止
2. 新しい双方向同期スクリプトに実行権限を付与
3. 手動で動作テスト
4. launchdで自動化

これにより、Mac/スマホのどちらでも読書ノートを編集でき、常に最新の状態が保たれます。

## 🚀 使い方

### 1. 新しい本を読み始める

```
あなた: 「サピエンス全史を読み始めます」
```

AIが自動的に：
- 本専用のディレクトリを作成
- 読書セッションを開始
- 対話の準備を整える

### 2. 読書中に質問・対話する

```
あなた: 「認知革命って具体的にどういう意味？」
AI: 「認知革命とは約7万年前に起きた...」

あなた: 「なるほど。でも、それって本当に革命と呼べるのかな？」
AI: 「素晴らしい疑問ですね。考えてみましょう...」
```

すべての対話が自動的に `logs.md` に記録されます。

### 3. 別の本に切り替える

```
あなた: 「7つの習慣に切り替え」
```

複数の本を並行して読んでも、それぞれ個別に管理されます。

### 4. 読書ノートを生成する

```
あなた: 「読書ノートを作って」
```

AIが対話ログを分析して、構造化された読書ノートを自動生成します。

生成される読書ノートには：
- 📖 本の概要
- 🔑 重要な概念・用語
- 💡 主な学び
- 🤔 あなたの考え・気づき
- ❓ 疑問点・さらに調べたいこと
- 📝 印象的な引用
- 🔗 関連書籍・リソース

## 🎨 読書ノートのサンプル

実際に生成される読書ノートのイメージ：

```markdown
# サピエンス全史 - 読書ノート

**読書期間**: 2025-11-01 - 2025-11-05

## 📖 本の概要
人類の歴史を認知革命、農業革命、科学革命の3つの革命から解き明かす壮大な物語...

## 🔑 重要な概念・用語
- **認知革命**: 約7万年前、ホモ・サピエンスが虚構を信じる能力を獲得...
- **農業革命**: 1万年前の定住生活の始まり...

## 💡 主な学び
1. 人類の成功の鍵は「協力」する能力
2. 虚構（物語）が大規模な協力を可能にした
...
```

## 💡 便利なコマンド

| コマンド | 説明 |
|---------|------|
| `[本のタイトル]を読み始めます` | 新しい読書セッション開始 |
| `[本のタイトル]に切り替え` | 別の本に切り替え |
| `読書ノートを作って` | 読書ノートを生成 |
| `ここまでの読書ログを見せて` | logs.md の内容を表示 |
| `読んでいる本のリストを見せて` | 30_Knowledge/20_Books/ 内の本を一覧表示 |
